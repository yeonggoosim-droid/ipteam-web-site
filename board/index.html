구글 시트 연동은 Apps Script를 중간 다리로 쓰는 방식이 가장 현실적입니다. 코딩 지식 없이도 복붙으로 설정 가능하게 단계별로 안내드립니다.

상황판 웹앱(브라우저)

Google Apps Script (무료 서버 역할)
    ↕
Google Sheets (데이터 저장소)

브라우저가 직접 구글 시트에 접근하면 보안 문제가 생깁니다. 그래서 구글이 제공하는 Apps Script를 "중간 서버"로 세워서, 상황판 ↔ Apps Script ↔ 시트 순으로 데이터를 주고받습니다. 모두 무료입니다.

STEP 1 — 구글 시트 만들기

구글 드라이브에서 새 스프레드시트를 만들고 이름을 팀상황판으로 짓습니다. 시트1 이름을 tasks로 바꿔주세요(시트 탭 더블클릭).

첫 행에 다음 헤더를 정확히 입력합니다:

ABCDE
memberweekKeydayIdxtaskTextcategory

weekKey는 2026-W26 형식으로 주차를 구분합니다. 데이터는 이 형태로 쌓입니다.

STEP 2 — Apps Script 배포

시트에서 확장 프로그램 → Apps Script를 클릭합니다. 열리는 편집기에서 기존 코드를 전부 지우고 아래를 붙여넣습니다.

파일 생성됨, 파일 읽음
완료

위 파일 내용을 Apps Script 편집기에 붙여넣은 뒤, 다음 순서로 배포합니다.

  1. 우측 상단 배포 → 새 배포
  2. 유형: 웹 앱
  3. 실행 계정: 나(본인)
  4. 액세스 권한: 모든 사용자 (익명 접근 허용)
  5. 배포 클릭 → 팝업에서 액세스 승인
  6. 나오는 웹 앱 URL 복사 (https://script.google.com/macros/s/... 형태)

STEP 3 — 상황판에 URL 붙여넣기

아래가 구글 시트 연동이 완성된 상황판 앱 파일입니다. SCRIPT_URL 부분에 방금 복사한 URL만 넣으면 됩니다.

마지막 연결 작업 (2분)

status_board.html 파일을 메모장(또는 VSCode)으로 열어서 딱 한 줄만 수정합니다.

const SCRIPT_URL = 'YOUR_APPS_SCRIPT_URL_HERE';

이 부분을 STEP 2에서 복사한 URL로 교체하면 됩니다. 예를 들면:

const SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb...xYZ/exec';

단점: 팀원끼리 실시간 공유는 안 됨 (각자 따로 관리)
